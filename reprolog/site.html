Debug from the actual request

No more guessing from a stack trace. Everything around the failure is saved next to it.

Live activity

Requests stream in as they happen. Filter by status, path or duration and spot the slow ones.

Spans and logs together

Logfire and OpenTelemetry spans as a waterfall, with each log line attached where it was written.

One-click replay

Re-run the exact request in-process, with outbound HTTP and LLM calls served from the recording.

Outbound calls

httpx and requests calls, including OpenAI, Anthropic, Gemini and Groq, with bodies and token usage.

Private by default

Secrets are redacted, data stays in a local SQLite file, and the folder keeps itself out of git.

Read & write tokens

Hand a read token to a dashboard or a write token to CI to trigger replays through the API.
